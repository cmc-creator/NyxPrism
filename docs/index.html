Three Steps to a Clean Document Archive

No configuration files. No setup wizards. Drop a PDF in, get organised files out.

01

Drop Your Batch Scan

Feed NyxPrism any multi-document PDF — a day's worth of scanned mail, a stack of contracts, or an invoice run. One file, any size.

AI Finds Every Boundary

Common questions

FAQ

The essentials before you get started.

Do I need an API key to use the AI features?

No. AI Smart Split in the web dashboard is powered by Claude (Anthropic) — no configuration needed on your end. The CLI tool also has a built-in heuristic engine that runs with no API key and no cost.

Does NyxPrism send my PDF content to any server?

Everyday editing tools run in your browser. Cloud AI, signature requests, and document distribution send only the content needed for the workflow you choose. See our Privacy Policy for full details.

What can I do in the dashboard?

Edit, organize, convert, OCR, redact, protect, sign, and distribute PDFs from one visual workspace. AI tools are available when you need deeper document analysis.

Is Tesseract OCR required?

Only for the ocr command or AI analysis of image-only scanned PDFs. Install separately (sudo apt install tesseract-ocr on Linux, brew install tesseract on macOS). For PDFs with a selectable text layer, OCR is not needed.

Can I use NyxPrism as a Python library, not just CLI?

Yes. Every command has a corresponding Python function. Import from nyxprism.core.* and nyxprism.ai.* to integrate directly into your own scripts and applications.

For developers

REST API

Automate PDF workflows from your own code with the NyxPrism REST API — authenticated by the keys you generate in the dashboard.

Everything the dashboard can do, as an API

Generate an API key from your dashboard, then call the same backend that powers the web app — with full subscription gating and per-key tracking.

  • Keys use the format nyx_<64 hex chars> — never exposed after generation
  • SHA-256 hashed at rest, never stored in plaintext
  • Each key tracks last_used_at so you can audit access
  • Subscription gating enforced on every request — inactive accounts are rejected
  • Up to 5 active keys per account — rotate freely
